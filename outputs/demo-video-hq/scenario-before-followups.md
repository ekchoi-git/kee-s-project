# 셀리 신규 고객 소개 영상 시나리오

## 제작 기준

- **영상 길이:** 16:9 가로 영상. 60초는 참고 길이이며 초과해도 된다. 입력과 결과를 읽을 수 있는 속도를 우선한다. 처리 대기는 최대 5초만 담고 이후 대기 구간을 잘라 실제 완료 결과로 전환한다. 5초 전에 완료되면 즉시 결과로 전환한다.
- **핵심 흐름:** 열린 창 연결 확인 → 회사별·연도별 지불금액 집계 요청 → 새 시트 확인 → Excel 저장.
- **제품 사실:** 현재 셀리에는 별도 계정 로그인·검색창·자체 저장 버튼이 없다. API 키는 설정 창에서 확인하고, 자연어 요청은 열린 회사별·연도별 합계를 새 시트에되며, 결과 파일은 Excel에서 저장한다. 영상에서 존재하지 않는 버튼이나 기능을 연출하지 않는다.
- **음성 선택:** **없음**. 한국어 하단 자막과 신나지만 시끄럽지 않은 배경음·클릭 효과음만 사용한다. 추후 음성을 선택하면 이 파일의 자막을 내레이션 초안으로 쓰고 장면 길이를 다시 맞춘다. OpenAI TTS 선택 시 모델은 `gpt-4o-mini-tts`, 톤은 차분하고 친근하며 또렷한 한국어로 한다. 이 단계에서는 음성 생성·API 호출을 하지 않는다.
- **시연 데이터:** 개인정보가 없는 데모 Excel 파일. 화면에 실제 API 키, 계정 정보, 민감한 파일 경로가 보이지 않도록 준비한다.

## 화면 연출 기준

- 가상 커서는 실제 조작 위치를 따라 이동한다. 클릭마다 0.3–0.5초 링을 표시하며, 같은 장면에서 불필요한 반복 클릭은 넣지 않는다.
- 하단 자막은 한 번에 최대 두 줄로 표시하고 Excel 표의 핵심 값과 겹치지 않게 파란 그라데이션 자막창을 둔다.
- 하이라이트는 파일 선택, 작업 시트, 입력창, 보내기, 작업 완료, Excel 결과, 저장 동작에만 사용한다.
- 앱은 PySide6 데스크톱 UI이므로 `data-testid` 대상이 아니다. 녹화 단계에서 조작 대상을 식별할 수 없으면 접근성 이름 또는 Qt `objectName`을 먼저 점검하고 필요한 요소에만 추가한다. 이번 단계에서는 UI 코드를 수정하지 않는다.
- 실제 AI 처리 시간이 길거나 결과가 예상과 다르면 성공 화면을 꾸며 넣지 않는다. 정상 실행을 다시 촬영하고 기다리는 구간만 편집한다.

## 확정 디자인과 실행 준비

- 가운데 배경은 흰색. 상단 바·자막창·이름표는 짙은 파랑에서 밝은 파랑으로 이어지는 그라데이션이다. Excel 표 색에 맞추지 않는다.
- 상단 바: `#173B94 → #5795EF`, 자막창: `#173B94 → #4B8BE7`. 실제 앱 화면은 촬영본을 사용하며 시안 이미지를 앱 화면 대신 넣지 않는다.
- 실행 시나리오: 같은 폴더의 `VIDEO_SCENARIO.yml`. 오늘 만든 YAML `demo-video`만 사용한다. Remotion 스킬은 사용하지 않는다.
- 데스크톱 실행기는 미리 열린 Python 셀리와 지정된 Excel 창만 연결한다. 모든 클릭은 새 화면 관측 후 대상을 확인해서 실행한다.
- 현재 준비 단계에서는 연결 확인과 설정 검증만 한다. 요청 전송·파일 저장·실제 녹화·최종 영상 및 GIF 제작은 하지 않는다.

## 가독성 개선 재촬영 (2026-11-03)

- JPEG로 축소된 UI 관측 이미지를 영상 원본으로 쓰던 문제를 수정했다. 원본 물리 해상도의 실제 PNG를 사용한다. Excel 창 타이틀 캡처의 검은 화면은 사용하지 않고, 동일한 실제 원본/결과 화면을 데스크톱 영역 PNG로 보충 촬영하여 원본과 출처를 capture.json에 기록했다.
