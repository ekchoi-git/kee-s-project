    회사명 하나로 합치기

  2. Case 2

    연도 직접 입력

    연도별로 거래금액을 정리하는데, 데이터의 날짜가 텍스트로 출력되어 연도를 수작업 입력

  3. Case 3

    거래유형 구분

    회사별 거래유형이 정리되지 않아, 전표 내용을 하나하나 보면서 거래유형을 수작업 구분
